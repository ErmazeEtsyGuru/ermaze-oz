FILES

BEFORE PUBLISHING
1. Open index.html in Notepad or another editor.
2. Search for:
   REPLACE-WITH-YOUR-EMAIL@example.com
3. Replace it with an email address you control.
4. Save the file.

FASTEST HOSTING OPTIONS
- GitHub Pages
- Netlify
- Cloudflare Pages
- Wix / another site builder

For Etsy's Website URL field, use the final public HTTPS URL, for example:
https://yourdomain.example/

Do not use:
http://127.0.0.1:8765
or another localhost address, because Etsy cannot access it publicly.

The page intentionally describes ERMAZE OS as a private seller tool for the owner's
own Etsy store and avoids claims that it copies competitors' designs.
